# ClashApps

这是clash-yacd应用包含clash和后台面板yacd

## 默认端口配置

| 默认参数配置                |                    |
| --------------------------- | :----------------: |
| 默认混合代理端口            |        7890        |
| 默认监听端口                |        9090        |
| 默认后台地址                |    192.168.0.0    |
| 默认后台端口                |        9999        |
| 默认配置文件config.yaml路径 | ./data/config.yaml |

## 备注：

注意！如果配置文件不存在或者映射路径不正确会导致应用启动失败

解决方法：重新编辑正确应用参数之后点击重建或者卸载重新安装
